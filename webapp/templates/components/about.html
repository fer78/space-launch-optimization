About the Project

Technical overview, methodology, and technologies used.

Project Overview

This project analyzes historical SpaceX launch data to identify the variables that most influence mission success and to build a machine learning model capable of estimating the probability of successful future launches.

Objectives

  • Perform exploratory data analysis.
  • Identify key success factors.
  • Train and evaluate predictive models.
  • Deploy an interactive dashboard.

Technology Stack

  • Python
  • Pandas
  • Plotly
  • Flask
  • Scikit-learn
  • HTML/CSS
